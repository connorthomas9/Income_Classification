## Overview
In this project, we will be taking data from the 1994 Census database in order to create a logistic regression model that will predict whether or not a person makes more than $50,000

The primary analysis takes place in the `ic_notebook.ipynb` Jupyter Notebook file

The dataset used for this project is the `adult.data` file, and comes by way of the `UCI Machine Learning Repository`

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of logistic regression models
